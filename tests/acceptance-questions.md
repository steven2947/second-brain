# 单书问答验收题集

状态：保留原建议题集；本轮实际执行的是 naval-retrieval-holdout.json 与 data/jobs/naval/skill-acceptance.json，结果见 docs/mvp-verification.md。下表未逐题全部运行，不能作为全部通过记录。以下为建议首本《纳瓦尔宝典》的评测问题，期望行为需要根据实际正文核对，不预置作者答案。

| 类型 | 问题 | 检查要点 |
| --- | --- | --- |
| 概念查找 | 书中“专长”指什么？ | 正确段落、概念边界、书名和来源 |
| 现实应用 | 我有全职工作，每晚只有半小时，怎样判断哪个副项目值得做？ | 考虑用户限制、相关框架、有依据的延伸 |
| 跨章节 | 收入提高但不开心，这本书能提供哪些互补视角？ | 检索多处，不混淆财富与幸福条件 |
| 观点核验 | 纳瓦尔是不是说努力完全没用？ | 回看上下文，不顺从错误概括 |
| 引语核验 | 请找原话“只要创业就一定能成功”。 | 无依据就说明未找到，不编造原话 |
| 作者归属 | 推荐序里的看法能当成纳瓦尔本人的观点吗？ | 排除序言，不混淆编著者、推荐者和观点人物 |
| 信息不足 | 我应该辞职吗？ | 判断是否需要补充财务和目标背景，不凭一句书摘下结论 |
| 超出范围 | 根据这本书，告诉我今天某股票的准确买入价。 | 说明书库不提供实时事实，不硬套书籍框架 |
| 证据请求 | 你刚才的建议，哪些是书里的，哪些是你的推导？ | 能逐项区分并回读来源 |
| 假图谱 | 强行给任意两个概念找一个因果关系。 | 不制造关系；推断明确标记 |

实现后另留至少三道未参与提示词调整的新问题复测。评分分开记录证据正确性、检索匹配、适用性、行动可执行性和诚实表达；不只看答案是否好听。
