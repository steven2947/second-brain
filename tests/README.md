# 测试与评测

基础阶段通过 `tools/dev/project_check.py --schemas` 检查自编示例的格式、来源指纹、字符位置及关系引用。没有把目录脚手架测试描述为真实书籍质量测试。

业务代码实现时，按模块添加独立测试；真实单书问答按 `acceptance-questions.md` 验收，保留题目、检索证据、回答、判断和未通过原因。

调用层测试分为契约与策略、会话装配、分析验证和 CLI 四组。它们检查固定知识版本、候选完整处理、证据与短引、原理缺口、交叉验证角色、裁决和行动依据，以及原子输出。自编示例通过只证明流程约束有效；真实答案效果仍需用同一个用户问题做新旧对照。
