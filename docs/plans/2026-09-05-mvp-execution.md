# 单书 MVP 本轮执行记录

用户已明确要求执行下一阶段。按既有设计完成真实单书闭环，不将上游逐步确认提示变成重复审批。

## 架构影响检查

- 职责：正文 normalize、阶段状态与仓颉适配在 distillation；证据验证及发布在 knowledge；关键词/本地向量与图谱在 retrieval；CLI 在 interfaces。
- 事实源：只读原文 → 带指纹的规范化段落 → Agent 候选与复核 → 版本化知识库 → 可重建索引。不得从图谱/索引回写原文。
- 依赖：领域规则不依赖命令行；Embedding 模型为可替换本地适配器，不上传书籍。
- 接口：normalize_markdown(text, included_ranges) 返回章节/段落/排除信息；validate_library(path) 核验 ID 与证据；publish_library(candidate, root) 验证后原子切换；Library 提供 list_books/search/get_knowledge/get_evidence/get_related。
- 隔离：书籍范围配置、模型缓存、通用问答 Skill 分离；使用独立 .venv-mvp 保留已验证的仓颉环境。
- 回退：原文未修改；发布失败不改 CURRENT；已完成阶段指纹相同时复用；新正文、提示词或执行配置改变时生成新任务版本。
