# 知识推演 v2 实施计划

## 用户可见目标

回答不只交付结论，还要让用户看到：调用了哪些书和卡、知识原理为何、如何映射用户事实、知识之间如何支持或反对，以及主持人为何作出当前裁决。展示的是可核验的知识推演记录，不是模型私密思维链。

## 六项架构影响检查

1. **职责**：`retrieval` 只召回；`orchestration` 验证知识推演；Skill 负责问题理解与用户可读表达。
2. **事实源**：原文证据、已验收卡片和用户显式事实为事实边界；答案包是派生物。
3. **依赖**：证据→卡片→检索会话→分析草稿→验证答案包→用户表达，不反向回写。
4. **接口与测试**：v2 使用独立 Schema，验证器同时保留 v1 兼容通道；真实问题另做效果验收。
5. **变化隔离**：不修改原书、已蒸馏卡、前端和检索引擎；只增强调用、核验与表达层。
6. **迁移回退**：v1 产物仍可验证；v2 未通过真实题验收前不取代 v1，可单独回退 v2 新文件与分支逻辑。

## 实施顺序

1. 新增 v2 `AnalysisDraft` 和 `AnswerPacket` Schema，保留 v1。
2. 验证用户事实索引、入席卡机制、论证关系、圆桌席位、裁决与学习收获。
3. 将 v2 契约写入通用 Skill 和答案表达规则。
4. 完成 167 本可验收书的候选库编译和全库检索压测。
5. 用同题旧版/v2 对照请用户验收；通过后再扩展到五类问题。
6. 自动测试和用户效果验收都通过后，才提交并推送远端。

## 效果验收门

- 回答必须先回应真实问题，不得用架构术语压过用户问题。
- 用户不看卡片 ID 也能理解原理和分析过程。
- 展示实际搜索范围、入席与淘汰，但不用候选数量制造虚假“全库都赞成”。
- 每个核心结论可回溯至用户上下文和入席卡；每张入席卡都有机制与边界。
- 没有真实反方或替代方案时展示缺口，不虚构角色。
- 必须给出改判条件，并让用户带走至少一个可复用方法。

## 2026-09-07 效果回退修复

原因已定位：旧表达规则压缩开头、Agent成稿丢失推演、批量默认淘汰理由掩盖取舍、测试只看字段与PASS字样。已撤回旧五题效果通过结论。按两次法则重审职责：机器负责可确定的引用与覆盖检查，Agent负责真实逐卡判断和成稿语义审阅，用户负责主观效果反馈，不用固定篇幅/卡数/角色数替代质量。

- 职责：修改表达规则与效果材料装配器；增加只读最终书目核对工具，不改检索与蒸馏。
- 事实源：沿用首题原request与session；新稿存revision-2，保留旧稿。
- 依赖：显式取舍→已验证答案包→自由表达→确定性书目核对与语义对照。
- 接口：装配器新增必填rejected_decisions，缺失不再自动补齐；旧规格仍留档，但需补齐真实决定才能重新装配。
- 隔离：工具只核对显式《书名》和末尾指令，不宣称校验语义；测试用自编故障数据，不依赖私有书库才能复现。
- 回退：旧文案、旧报告保留并加更正说明；未通过用户效果确认前不冻结新基线。

验证顺序：重做同一道副项目题；核对最终引用与包一致；用相同题目列出具体判断变化；通过后再推广到其余四题，不能把文案改好一篇等同于端到端生成稳定。

## 2026-09-07 自适应澄清接入（用户已确认范围）

1. **职责**：新增 orchestration/intake 问题档案领域模块，计算轮数、状态及请求；AI 自主提问、整理事实与检索焦点，CLI 只负责持久化。首次正式分析关闭主动背景澄清，用户自发深化仍可更新档案。
2. **事实源**：保留原问题、逐次用户消息和有理由的档案变更；事实/约束/假设/未知分开。事件日志是当前快照的来源，摘要及检索焦点是 AI 派生物，机器不声称验证了消息语义。
3. **依赖**：事件→问题快照→CallRequest→既有 analyze/validate-analysis；不读写原书、蒸馏成果和前端。
4. **接口与测试**：新增 intake-start/update/show 与 analyze --problem；原 --request 兼容。最多3轮、提前停止、等待回应、修订冲突、后续新事实、请求/答案包上下文透传及同题检索前后对照分别测试。锁定同一档案路径、校验 expected_revision，防止多窗口覆盖。
5. **变化隔离**：问题上下文作为可选字段，旧会话保持可验证。编译时把目标与 retrieval_focus 放入检索扩展，剩余最多5个自由角度；发现原检索引擎最多5条而请求契约允许6条的不一致，一并修正为6条，不改变排序算法。更新事实后旧焦点作废，必须重新准备分析。
6. **迁移回退**：旧请求/会话/答案保留；新分析用独立文件，可显式关联上一会话。档案事件追加不清空计数、不重写旧答案；回退时停止使用新入口即可，不迁移书库。

本轮不接自动模型服务，不声称 CLI 自动识别用户意图或自动生成好问题。轮数硬约束只覆盖同一档案的规范入口，不能防止外部 Agent 新建档案或绕开入口；Skill 禁止通过这些方式重置同一问题计数。技术通过与真实回答效果分开记录。
