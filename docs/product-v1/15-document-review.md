## 自检发现并已修正

| 问题 | 修正 |
| --- | --- |
| 测试示意goal曾写成decision | 核对已有schema后改act；明确完整合法枚举 |
| 学习运行没有独立outcome | outcome补learning，学习成品保存在learning_turns而非假装现实答案 |
| 计量只区分run/attempt不够 | 增加call_index/call_purpose，逐次计量再汇总 |
| 仅job保存幂等不足 | 独立idempotency_records覆盖无job的建档请求；重放仍实时鉴权 |
| 3D/账户页面目录名称不一致 | 统一auth/settings和mascot边界 |
| 模型模式local-model/local不一致 | 配置统一disabled/demo/local/provider |
| 提到升级知识但没有完整迁移接口 | 首版固定release；换库新建问题，不提供假的一键迁移 |
| 管理MFA、权利审查只有口号 | 补逻辑字段、challenge、管理API与测试门槛 |
| 导出/导入事件未覆盖 | 补job状态接口及受授权的export_ready/import_ready |
| 撤权可能被误解为远程收回已下载材料 | 明确只控制后续获取，不能保证收回截图/已下载文件 |
