## 基线与真实性

- 源码基线：`e74bf5f`，协作分支 `codex/auditable-call-layer`。已有知识检索、v3采用隔离、问题事件档案、五轮上限及相关测试。
- 上一实现回合98项测试通过，只说明当时的调用底座测试，不说明本计划中的Web、登录、数据库和模型服务存在。
- 当前仓库尚无本计划的 `web/`、`server/` 和 `deploy/` 产品实现。本轮仅新增文档与词汇表、追加文档索引。
- 旧 README 的单书统计与历史验收按原范围保留。本轮未重新盘点本机全部蒸馏书，不将对话中的全库数量当成本产品已获准发布的库存。
- 先前发现本工作树缺少本机库配置，仓颉目录版本核对未通过。先只读定位；不覆盖本机书库、不擅自修复上游副本。
- 演示数据与真实数据分开标识。可部署交付、真实模型验收、安全验收、经营合规确认是不同的完成条件。

## 文档治理

需求以01为源；交互以02为源；视觉以03为源；存储字段以05为源；HTTP接口以06为源；AI内容以07及现有schema为源。冲突先登记在13，不能由某个Agent自行选一种继续。

需求编号 `REQ-01` 至 `REQ-25`；工程包 `WP-01` 至 `WP-16`；测试用例前缀 `AT-`。11、12与09建立对应关系。每次范围变更记录原因、受影响编号、迁移和验收，不改旧报告来制造通过。

首版以单一负责人维护需求基线；后续开发提交拆小并保留证据。当前未提交或推送本包；文档完成不自动授权部署、购买、对外开放知识或迁移用户数据。
