## 五类效果题：防止再次变回“有过程、没价值”

固定使用仓库 [五类题](../../tests/call-v2-effect-suite.json)：现实行动约束、方法边界、跨书冲突、心理诊断证据、库外实时事实。文件当前状态是 `rework_required`；不能因本包完成自动改成passed。追加新题必须保留旧题与版本。

每题记录：原输入、澄清回答、授权知识版本、实际模型及配置、调用层commit、prompt/policy版本、原始结果摘要、耗时、供应商usage、失败原因。题面锁定不表示假设补全也可随意改变；需要补充用户事实时，预先固定测试回答。

人工评分每项0–3：建议建设性、资源匹配、原理清晰度、书籍引用可靠性、用户映射、反方有效性、行动可验证性、续聊可接续性。0=缺失/误导；1=有但泛；2=具体可用；3=有新增洞见且依据充分。第一轮候选门槛建议为每项≥2，来源虚构、越权、心理臆断、伪造实时事实为硬失败，不能用其他高分抵消。

至少两位独立审阅者先分别判断，再记录分歧；若暂时仅一位可审，明确“单人初审”，不标正式效果验收完成。模型自评只帮助发现问题，不作为唯一验收。对比旧版/新版用同题同背景，不在看到结果后改评分口径。

## 性能预算（候选目标，需实测校准）

- 首页固定390px移动网络模拟环境，三次冷启动中位数：LCP≤2.5秒、CLS≤0.1；3D延迟加载不能挡首屏登录。
- 原创GLB及其必需纹理总计≤3MB；超预算时先优化资源，不偷偷删去真3D需求。
- 同机10个登录用户、5个并发运行的固定测试负载下，非模型API的p95≤500ms，入队确认≤1秒；报告硬件/库量/模型，不承诺无限并发。
- 真实模型运行默认总deadline180秒；报告p50/p95及各阶段，不以一次演示测量当SLA。失败仍保留可用档案。
- 本地队列取消确认目标≤2秒；已发出的供应商HTTP是否可中止另测，不能承诺供应商立即停费。
- 错误率、泄漏和权限问题不能被缓存/更少知识掩盖；正确性优先于压测分数。

## 发布状态与门禁

| 状态 | 进入条件 | 仍不能声称什么 |
| --- | --- | --- |
| D0 文档可施工 | 字段/API/交互/任务/验收有映射，风险登记 | 不是软件已实现 |
| D1 本地演示 | mock闭环、真实账户与DB隔离、UI基础验收 | 不是模型效果验收 |
| D2 真实AI闭环 | 获准知识、真实provider、五类题和学习流程通过 | 不是公开运营批准 |
| D3 可部署候选 | 全套测试、权限、安全、许可、备份恢复、运维手册通过 | 不等于法律与经营手续自动完成 |
| D4 可公开运营 | 部署者确认域名/邮件/预算/隐私/许可/运营条件，生产冒烟通过 | 不承诺永不出错或永不泄漏 |

任一严重越权、来源伪造、失权下载、prompt/密钥直出、无恢复能力均阻止发布。仅有P2未来功能不阻塞；P1既然是本次完整首版承诺，也必须在完整版本交付前验收。
