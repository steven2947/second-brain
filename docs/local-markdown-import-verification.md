## 硬性保护

- 未人工 accepted 的书默认拒绝导入。
- `--allow-ready` 只生成评测候选，不自动发布。
- 原文 SHA-256、卡片 `source_hash`、`char_span` 和短引任一不一致即失败。
- 证据库只保留离散短引，原文路径和整书不进入默认分发包。
- 本地卡片 ID 保持不变，便于从答案回到蒸馏产物。
