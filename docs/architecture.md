# 架构设计与影响检查

## 职责与依赖

| 模块 | 职责 | 允许依赖 |
| --- | --- | --- |
| knowledge | 元数据、知识卡片、关系、证据、验证规则 | 通用数据类型与格式契约 |
| distillation | 正文范围、任务状态、仓颉适配、卡片验收 | knowledge、文件与模型适配器 |
| retrieval | 检索、过滤、关系展开、证据读取 | knowledge、存储与索引适配器 |
| orchestration | 固定版本的候选会话、分析草稿验证、答案包装配 | knowledge、retrieval、调用契约 |
| interfaces | CLI、后续 Agent 工具协议 | 已定义的领域能力 |
| skills | 问题理解和结果综合 | 公开查询接口或明确的数据文件契约 |

五个模块已实现本地 CLI 单书及可审计调用闭环。证据规则位于 knowledge/evidence.py，正文解析依赖证据规则；orchestration 只读取固定知识版本，不回写事实源。工具位于 tools/dev/，负责盘点、自检和检索评估。

## 六项架构影响检查

1. **职责归属**：采用上述四个业务模块；仓颉适配独立于 Agent 问答，界面不承载蒸馏或知识规则。
2. **事实源与派生物**：规范化正文及其原文映射是证据源；已验收卡片与图谱是发布知识版本；搜索索引和交付文件从知识版本派生。修改通过蒸馏任务与验收入口写入，不回写原书。
3. **依赖方向**：来源 → 知识结构与验证 → 检索/应用 → CLI/Agent 适配。领域层不能读取浏览器状态或拼接页面。
4. **接口与测试接缝**：知识验证、关系展开、章节覆盖计算均为可独立测试的规则。模型调用、磁盘写入与搜索引擎通过适配器隔离。结构检查不替代语义核验。
5. **变化隔离**：作者配置与通用问答规则分开；模型参数、存储参数和作者知识不共用易变配置；新书不要求修改 Skill 主流程。
6. **迁移与回退**：记录 schema、正文、提示词和依赖版本；索引可重建；新知识版本验收通过后切换，失败保留上一版本。当前没有旧应用数据迁移。

结论：按模块边界开始，不需要对现有系统做架构改造；不启用 OpenSpec。后续若新增职责越过上述边界，先重新检查，不把领域规则堆入入口脚本。

## 已实现查询接口

| 能力 | 输入 | 返回 |
| --- | --- | --- |
| list_books | 可选作者 | 书目、覆盖范围、知识版本、处理状态 |
| search_knowledge | 原问题、扩展检索语句、可选书籍/作者、条数上限 | 卡片摘要、稳定 ID、来源、匹配方式与排序信息 |
| get_knowledge | 卡片 ID | 完整观点、理由、条件、边界、证据引用 |
| get_evidence | 证据 ID、上下文范围 | 原文片段、书名、章节、正文位置、来源版本 |
| get_related | 节点 ID、关系类型、最大跳数 | 有方向的关系、目标卡片、原文或推断依据 |
| analyze | 调用请求、深度、检索模式和策略 | 固定版本的候选卡、证据、关系与调用会话 |
| validate_analysis | 调用会话、逐卡决定和分析草稿 | 经来源与结构验证的答案包 |

所有返回包括 `schema_version`；已知错误区分 `NOT_FOUND`、`LIBRARY_NOT_READY`、`SOURCE_VERSION_MISMATCH`、`INVALID_ARGUMENT`。无搜索结果是正常空结果，不能编造替代材料。

相关性分数不是事实可信度。初期不定义跨引擎统一“置信度百分比”。

## 可审计调用层

`analyze` 只完成确定性检索和证据装配，不按相似度自动采用知识。Agent 对每个候选作出采用或淘汰决定，说明原理、情境映射和分析角色；`validate-analysis` 再核对知识版本、候选覆盖、卡片与证据 ID、短引、裁决依据和行动停止条件。

调用会话保存当次策略快照。同一会话必须使用同一策略验证；策略可以调节召回数量和展示方式，不能关闭版本、证据和来源硬规则。答案包属于派生产物，不回写书库。

## 文件读取模式

CLI 不可用时 Skill 可读取显式提供的卡片文件：`cards/*.json`、`evidence/*.json`、`relations.json`。没有书库时先说明尚未入库；不得把目录盘点当作知识检索结果。工具模式已通过 src.interfaces.cli 接入，具体命令见 usage.md。

## 知识图谱

核心关系：`depends_on`、`contrasts_with`、`composes_with`、`limited_by`。关系带稳定 ID、起点、终点、依据类别及证据 ID；系统推断明确标记 `inference` 并说明推导理由。

第一版用 JSON 有向边及有界 BFS 查询图谱，BM25 + 本地中文 BGE 向量 + RRF 排序；向量缓存为可重建 NPZ。无需独立向量数据库或图数据库服务。书库量增长后再评估存储替换。

发布以完整快照为单位，CURRENT 原子切换，旧版本保留。当前未实现多个独立书库的自动合并；不得将发布单书候选误当追加一本书。当前作者入口仅验收纳瓦尔。
